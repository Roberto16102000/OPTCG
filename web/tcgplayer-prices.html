Cómo ejecutar

  • Sin API: abre con cualquier servidor estático, p. ej. npx serve . -p 3456 → /web/tcgplayer-prices.html
  • Las peticiones van a https://optcgapi.com (CORS permitido, sin proxy).
  • API oficial: npm run tcgplayer:prices (proxy en puerto 3460)
  • Abre: http://localhost:3460/web/tcgplayer-prices.html
  • El proxy reenvía a https://api.tcgplayer.com (versión v1.39.0)
